Swift by Example - for

摘要Swift使用 for 和 while 来进行循环控制。使用方式主，一种为 for in ，一种为 for条件递增 。

作者 wanqing

Swift使用for和while来进行循环控制。使用方式主，一种为for-in，一种为for条件递增。

// for 循环

// 1
for i in 1...3 {
    println(i)
}

// 2
for j in 1..<3 {
    println(j)
}

// 3
for _ in 1...3 {
    println("hello, swift!")
}

// 4
for var index=0; index < 3 ; index++ {
    println(index)
}

上面代码中，1－3均为for-in方式，区别在于1使用了...语法，i的值从1到3，区别于1..<3，则不含3。

方式3中，使用了_来忽略循环的值。

最后的方式4则是类似于C语言的for条件递增循环。

最后输出：

$ swift for.swift
1
2
3
1
2
hello, swift!
hello, swift!
hello, swift!
0
1
2
