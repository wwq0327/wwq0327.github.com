## 已完成（对应 Issue #2）

- 隔离目录 `site/`，独立 npm 项目，不影响根 Hexo 构建
- 共享布局、页头、页脚与 11 条路由：
  - `/`、`/projects/`、`/projects/{id}/`、`/writing/`、`/writing/{slug}/`
  - `/videos/`、`/videos/{id}/`、`/about/`、`/subscribe/`、`/index/`、`/404.html`
- 统一内容模型（`site/src/lib/schema.ts`）：
  - Person、Project、Work、Activity 公开字段；Source 单独放在 `site/data/internal/sources.json`
  - `visibility` 为 `public | sample | draft`；`verification` 与 `visibility` 分开
  - 未知日期允许 `null`；`work.dates.updated/published` 不得早于 `authored`
  - 视频必须有 `media`；标记 `verified` 的项目必须至少有一个 http(s) 入口
- 内容校验：`npm run validate` 检查字段、重复 ID、关联引用与内部来源引用
- 合成样本：3 个项目、4 篇作品（3 文章 + 1 视频）、3 条动态，全部 `visibility: sample`
- 样本保护：全站显示“示例内容”横幅，输出 `noindex,nofollow`；候选文章/项目没有作为正式公开数据写入
