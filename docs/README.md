## 接手后的第一件事

确认用户这次是讨论方案、整理资料、实现流程，还是执行一次更新。不要把用户“读取此流程”理解成部署授权。明确进入实施后，再完成尚缺的环节并更新本表；实际检查优先于此表的历史描述。

当前没有生产维护运行日志、来源游标、发送账本或生产发布记录。本地已有 [新站骨架](维护记录/2026-11-07-新站骨架.md)、[设计还原与阅读页](维护记录/2026-11-07-设计还原与阅读页.md)、[内容迁移与真实内容](维护记录/2026-11-07-内容迁移与真实内容.md) 与 [重构基线](重构基线-2026-11-07.md)，它们不代表线上运行。未来落地时需指定这些记录的保存位置；不要自行宣称已有。可以从模板建立记录，订阅数据和凭据永不写入公开Git。

本目录和根AGENTS.md为执行入口；design/下此前的草案是参考。与最新用户指令冲突时遵循最新指令，并在得到记录授权时更新相关文档。
